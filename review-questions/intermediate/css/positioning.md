# What is the difference between static and relative positioning?
Static positioning is where the element is placed where it is normally. Relative positioning puts an offset on the default positioning of the element.
# What is absolute positioning useful for?
Absolute positioning is useful for when you wish to place an item outside the normal flow of the document.
# What is the difference between fixed and sticky positioning?
Sticky elements are fixed at the end of the screen as you scroll past it while fixed positioning places elements relative to the viewport.
