# What does the async keyword do?
used to declare an asynchronous function
# What does the await keyword do?
waits for an asynchronous function to complete before using the result
# What is returned from an async function?
a result or an error message
# What happens when an error is thrown inside an async function?
the code inside the catch block runs
# How do you handle errors within an async function?
with code inside the catch block
