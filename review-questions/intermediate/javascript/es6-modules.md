# Before ES6 modules, how would you privatize a variable from being accessible in other files?
Using an immediately invoked function expression.
# Before ES6 modules, how would you expose variables to be accessible in later files?
Returning a value in an immediately invoked function expression?
# What are some benefits of writing code in modules?
You can control the scope of variables.
# What is the difference between default and name exports?
Default exports can be renamed during import while named exports have to be imported with the variable name.
# What is an entry point?
Linking a file into a HTML document.
# How do you link a module script in HTML?
<script src="name.js" type="module"></script>
