# What is Big O?
maximum running time of an algorithm
# What are the most common Big O notations?
O(1), O(n), O(nlogn), O(n^2)
# Why use Big O?
It allows us to find algorithms that are efficient
# What is big Omega and why isn't it as useful?
minimum running time of an algorithm
# Why don't constants make a difference in Big O?
Constants become negligible with large input size
