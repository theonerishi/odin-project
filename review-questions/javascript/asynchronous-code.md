# What is a callback?
A callback is a function that gets passed into another function
# What is a promise?
An object that may return a value in the future. They allow code to be run asynchrously that means that the computer only runs one function at a time.
# When should you use promises over callbacks?
Something called callback hell may occur- where the computer gets stuck with too many callbacks
# What does the .then function do?
Once the promise returns resolve or reject the .then block runs the code in its function
